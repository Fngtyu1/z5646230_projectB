# AI workflow pack

This folder records the actual Codex-assisted workflow and the student's verification decisions:

- `AI_NOTES.md` — scope, constraints, corrections, checks, and remaining student responsibilities.
- `01_brief_and_backtest_prompt_log.md` — Project A reuse, walk-forward funds, calendar logic, and no-look-ahead correction.
- `02_sentiment_and_innovation_prompt_log.md` — finance lexicons, signal timing, discovery/holdout separation, turnover, and cost robustness.
- `03_app_report_and_qa_prompt_log.md` — Streamlit, report, visual QA, and the deployment boundary.

The root `AGENTS.md` is the project-specific working contract. Together these files distinguish AI-drafted work from the student's required interpretation, approval, deployment, and submission.
